Подключение движка к НейроРейтингу

Сайт работает как набор HTML-страниц и локальных изображений. Для GitHub Pages сборка на сервере не нужна. Разметку, стили и данные можно перенести в шаблоны своего движка.

Файлы проекта

ПутьНазначение
site/catalog-data.json.gzПолные тексты, метатеги, категории и настройки карточек.
site/assets/data.jsОблегчённые данные для поиска, фильтров и сравнения в браузере.
site/tools/ID.htmlСтраницы сервисов с обзорами и связанными материалами.
site/category/ID.htmlКатегории; последующие страницы имеют суффикс -page-N.
site/assets/imported/Локальные превью, большие снимки и логотипы.
generator/Генератор HTML из подготовленных данных.

Полный JSON хранится в gzip-архиве без потери данных. Генератор читает .json.gz напрямую; для импорта в свой движок распакуйте файл стандартной утилитой gzip или библиотекой своего языка.

Схема данных

Корневой объект содержит массивы tools, categories, articles и collections. Поле id — постоянный ключ и часть адреса страницы. При подключении базы сохраняйте существующие ID и внутренние ссылки.

Поле карточкиИспользование
name, description, contentНазвание, вводный текст и HTML обзора.
meta_title, meta_descriptionМетатеги конкретной страницы.
categories, tagsID категорий и поисковые метки.
cover, detail_cover, logoОтносительные пути к локальным изображениям.
price, pricing_typeПодпись условий доступа и фильтр free/freemium/paid. Неизвестное значение оставляется пустым.
capabilities, languagesЯвно заданные фильтры: api, open-source, local и языки.
score, category_scores, score_statusВнутренние баллы и значения по ID категорий. Текущая шкала — owner_assigned; это отдельное поле от пользовательских отзывов.
pinnedМолекула закреплена первой при отображении категории.
canonical_idСтарый псевдоним карточки; не должен появляться второй записью в списках.
schema_typeТип сущности в структурированных данных: SoftwareApplication для приложения или Organization для агентства.

Сценарии Молекулы

Объект molecula_offer у категории содержит title, task, steps, prompt, url, cta, screenshot, screenshot_caption. Сценарий категории отображается также на страницах связанных сервисов. Собственное поле molecula_offer карточки имеет приоритет и позволяет связать конкретный обзор с подходящим этапом работы. Общий сценарий находится в корневом molecula_offer; отдельные страницы можно настроить через pages_molecula_offers по относительному HTML-адресу.

Поле mode различает выполнение задачи и подготовку материалов: direct или preparation. Ссылки ведут на конкретные HTTPS-страницы Молекулы, скриншоты хранятся локально. Обновляйте сценарий вместе со ссылкой и изображением при изменении функций сервиса.

Локальная сборка

Установите зависимости генератора и соберите результат в отдельную папку. Параметр --base задаёт окончательный адрес: по нему формируются canonical, Open Graph и sitemap.

python3 -m pip install -r neyrorating/generator/requirements.txt
python3 neyrorating/generator/build_catalog.py \
  --source neyrorating/site \
  --input neyrorating/site/catalog-data.json.gz \
  --out /tmp/neyrorating-built \
  --base https://cflexdesign.github.io/moleculs_seo/neyrorating/site/

При удалении карточки из данных передайте её ID через --exclude-pages, чтобы удалить также сохранённую страницу и ссылки в подборках. Новые изображения должны находиться по указанным локальным путям в исходной папке.

Флаг --optimize-covers уменьшает размер крупных непрозрачных PNG-скриншотов за счёт WebP. Он меняет только папку результата; исходные изображения, логотипы и декоративные картинки сохраняются. Повторяемые SVG-иконки автоматически объединяются в локальный файл, сохраняя оформление страниц.

Что заменить при подключении сервера

Избранное, отзывы и форма предложения сейчас сохраняют данные локально в браузере или скачиваемом файле. Подключите свои обработчики, базу данных и модерацию. Пользовательские оценки храните отдельно от внутреннего балла редакционного списка.

Если движок формирует HTML сам, сохраните по одному H1, title, description и canonical на страницу; Open Graph должен указывать тот же адрес. Пагинация и связанные материалы должны иметь обычные ссылки, доступные без JavaScript. Обновляйте sitemap после изменения данных.

Изображения сервисов, favicon и шрифты локальные. Форму, загрузку данных и авторизацию подключайте к своему серверу, сохраняя текущие классы компонентов для оформления.
