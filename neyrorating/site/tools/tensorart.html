Для каких задач

Tensor.art рассчитан на задачи, где нужно получать изображения из словесного задания. Ещё одно направление работы: собирать видео с цифровым ведущим.

Проверка на своей задаче

Начните с понятного материала для «Tensor.art»: подготовьте одну сцену с главным объектом и заданным освещением.

После пробной задачи в инструменте «Tensor.art» посмотрите, остаётся ли объект узнаваемым при смене ракурса.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Tensor.art» «видео-аватары» подготовьте короткий сценарий и разрешённый образ персонажа. Затем сопоставьте движения рта с речью и проверьте произношение имён.

Для сопоставления задач откройте раздел AI-персонажи.
