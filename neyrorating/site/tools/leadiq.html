Какие задачи рассматриваются

«LeadIQ» связан с поиском потенциальных клиентов.

Сценарий для сравнения

Условия сравнения для «LeadIQ» стоит записать заранее. Подготовьте обезличенный запрос с бюджетом, сроком и требованиями и задайте цель: разобрать обращение потенциального клиента. Нужный режим и формат результата проверяются до основной работы.

Проверяя результат инструмента «LeadIQ», не добавляйте обещания, которых нет в условиях компании.

Другие варианты этого направления

Сопоставить инструмент «LeadIQ» с другими вариантами можно в разделах Автоматизация, Продажи.

Для «LeadIQ» можно также сравнить отдельный сервис и доступ к нескольким моделям через Молекулу.

Практика в Молекуле

Подготовить скрипт упорядочивания файлов

Опишите правила именования и сортировки файлов, чтобы получить пример автоматизации на Python. Это подготовка скрипта, который вы запускаете самостоятельно; сначала проверьте список предполагаемых изменений на копии каталога и только затем применяйте выбранные операции.

  1. Покажите примеры имён и желаемую структуру папок.
  2. Попросите режим предварительного просмотра без изменений файлов.
  3. Сверьте план перемещений на тестовой копии каталога.
Пример запроса

Напиши Python-пример сортировки счетов по месяцу из имени файла. Сначала нужен только список будущих перемещений без изменения файлов. Объясни обработку непонятных имён и совпадений названий.
