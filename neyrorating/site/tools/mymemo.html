Для каких задач

Проверка на своей задаче

Начните с понятного материала для «MyMemo»: подготовьте небольшой документ с выводом, аргументом и существенной оговоркой.

После обработки материала инструментом «MyMemo» проверьте, сохранена ли оговорка: без неё краткая версия может исказить вывод.

Дополнительный сценарий

Для дополнительной задачи в инструменте «MyMemo» «управление знаниями» подготовьте несколько связанных документов с разными версиями одного правила. Затем убедитесь, что ответ основан на действующей версии и доступен только нужным участникам.

Работа с файлами

Если в вашем проекте нужны файлы PDF, перед длительной работой с «MyMemo» проверьте пробный файл в целевом редакторе. Так можно заранее увидеть, сохраняются ли структура и нужное оформление.

Для сопоставления задач откройте раздел Конспекты и заметки.
