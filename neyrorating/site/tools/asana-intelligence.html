Какие задачи рассматриваются

Asana Intelligence обобщает сведения о проектах и помогает находить проблемные участки. Инструменты выделяют риски и просроченные задачи в текущей работе.

Сценарий для сравнения

Для оценки инструмента «Asana Intelligence» в этом направлении возьмите короткий бриф с адресатом, назначением текста и обязательными фактами. Сначала уточните доступность нужной операции, затем сравните результат с ожидаемым.

Проверяя результат инструмента «Asana Intelligence», уберите из результата обещания и сведения, которых не было в задании.

Сравнение по задаче

Сопоставить инструмент «Asana Intelligence» с другими вариантами можно в разделах Текст и чат.

Для «Asana Intelligence» можно также сравнить отдельный сервис и доступ к нескольким моделям через Молекулу.

Практика в Молекуле

Превратить общую просьбу в рабочий запрос

Уточните расплывчатое задание для текстовой модели через результат, исходные факты и ограничения. Инструкция роли промпт-инженера помогает собрать полный запрос; отсутствующие сведения оставляйте вопросами, чтобы черновик ответа не заполнял пробелы придуманными деталями.

  1. Запишите первоначальную просьбу и желаемый результат.
  2. Добавьте известные факты, формат и запрещённые допущения.
  3. Проверьте, что запрос не требует неизвестных сведений.
Пример запроса

Уточни просьбу «напиши ответ заказчику». Есть описание задержки поставки, но новая дата неизвестна. Составь полный запрос для короткого ответа с фактами, ограничениями и способом проверки обещаний.
