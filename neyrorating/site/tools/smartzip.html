Проверка на своей задаче

Начните с понятного материала для «SmartZip»: подготовьте объект с известными характеристиками и несколькими вариантами описания.

Оценивая результат инструмента «SmartZip», сверьте адрес, площадь и условия; сгенерированный текст не подтверждает состояние объекта.

Дополнительный сценарий

Для дополнительной задачи в инструменте «SmartZip» «генерация лидов» подготовьте описание нужной компании и небольшой список контактов для проверки. Затем проверьте свежесть контактов и причины, по которым они подходят запросу.

Для сопоставления задач откройте раздел Недвижимость.
