CrewAI

CrewAI служит средой для создания автоматизаций с участием ИИ-агентов. Разработчик может опираться на готовые модели и агентов либо собирать собственное решение открытыми инструментами. Основная задача среды состоит в организации связанной работы нескольких исполнителей, когда отдельные действия объединяются в общий процесс.

Проверка на своей задаче

Для первого задания в инструменте «CrewAI» используйте небольшую задачу, которую можно повторить на тестовых данных.

При оценке результата инструмента «CrewAI» предусмотрите остановку процесса и повторный запуск после сбоя.

Дополнительный сценарий

Для дополнительной задачи в инструменте «CrewAI» «генерация кода» подготовьте небольшую задачу в проекте, где уже есть проверка ожидаемого поведения. Затем просмотрите изменения до запуска и проверьте граничный случай.

Рабочее окружение

Для рабочего окружения с Python заранее определите, как вы будете передавать материалы в «CrewAI» и возвращать результат в проект. Наличие подходящего способа подключения нужно проверить для вашего варианта доступа.

Для сопоставления задач откройте раздел Генерация кода.

Практика в Молекуле

Получить черновик обработки CSV

Опишите структуру CSV и нужное преобразование данных, чтобы получить пример Python-скрипта с пояснениями. Код можно использовать как основу собственной программы: запуск, проверку зависимостей и сверку результата с исходным файлом выполните отдельно.

  1. Покажите заголовки столбцов и несколько обезличенных строк.
  2. Задайте правила отбора, сортировки и сохранения результата.
  3. Запустите пример на копии файла и сравните строки.
Пример запроса

Напиши Python-скрипт для CSV заказов: оставить завершённые, сгруппировать по товару, посчитать количество и сохранить новый файл. Объясни зависимости и обработку пустых значений в исходных данных.
