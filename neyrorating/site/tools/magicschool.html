Для каких задач

MagicSchool используют, чтобы готовить текст по теме и требованиям к содержанию. Ещё одно направление работы: готовить учебный материал и объяснения.

Проверка на своей задаче

Для первого задания в инструменте «MagicSchool» используйте короткий бриф с адресатом, назначением текста и обязательными фактами.

После обработки материала инструментом «MagicSchool» уберите из результата обещания и сведения, которых не было в задании.

Дополнительный сценарий

Для дополнительной задачи в инструменте «MagicSchool» «обучающие материалы» подготовьте тему с известным уровнем подготовки ученика. Затем сверьте ответ с учебным источником и посмотрите, объяснена ли причина решения.

Для сопоставления задач откройте раздел Нейросети.

Практика в Молекуле

Выбрать инструмент для первой задачи

Начните с одного конкретного результата: текста, изображения или разбора документа. Навигация Молекулы помогает найти нужный раздел; условия доступности функции проверьте в своём кабинете.

  1. Опишите ожидаемый результат одной фразой
  2. Выберите раздел под этот результат
Пример запроса

Мне нужен понятный ответ клиенту по условиям доставки из предоставленного документа. Помоги сформулировать задание модели и перечень проверок ответа. Недостающие условия оставь открытыми.
