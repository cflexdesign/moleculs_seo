Для каких задач

Mindsera используют для задачи: подготавливать озвучку текстового материала. Ещё одно направление работы: вести разговор о переживаниях и самочувствии.

Проверка на своей задаче

Начните с понятного материала для «Mindsera»: подготовьте несколько предложений с вопросом, числом и именем собственным.

При оценке результата инструмента «Mindsera» прослушайте окончания слов и ударения, а не только тембр голоса.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Mindsera» «психическое здоровье» подготовьте обычную ситуацию без чувствительных личных подробностей. Затем оценивайте границы общения; помощь программы не заменяет работу специалиста.

Рабочее окружение

Для рабочего окружения с iOS, Android заранее определите, как вы будете передавать материалы в «Mindsera» и возвращать результат в проект. Наличие подходящего способа подключения нужно проверить для вашего варианта доступа.

Для сопоставления задач откройте раздел Конспекты и заметки.

Практика в Молекуле

Конспект с опорными понятиями

Соберите учебный текст или свои записи и задайте формат конспекта. Молекула поможет выделить связи между понятиями; определения и примеры стоит сверить с исходным материалом.

  1. Приложите материал лекции
  2. Сравните определения с исходником
Пример запроса

Из этого фрагмента лекции сделай конспект: термины, связи между ними и два вопроса для самопроверки. Неполные места отметь, не дополняй их догадками.
