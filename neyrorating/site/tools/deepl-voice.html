Для каких задач

DeepL Voice рассчитан на задачи, где нужно подготавливать озвучку текстового материала. Ещё одно направление работы: переносить содержание материала на другой язык.

Проверка на своей задаче

Начните с понятного материала для «DeepL Voice»: подготовьте несколько предложений с вопросом, числом и именем собственным.

При оценке результата инструмента «DeepL Voice» прослушайте окончания слов и ударения, а не только тембр голоса.

Дополнительный сценарий

Для дополнительной задачи в инструменте «DeepL Voice» «дубляж и переозвучка» подготовьте небольшой отрывок с терминами и репликами разных участников. Затем проверьте имена, термины и соответствие перевода исходному смыслу.

Для сопоставления задач откройте раздел Дубляж и переозвучка.

Практика в Молекуле

Реплики для переозвучки инструкции

Подготовьте новый текст озвучки к существующей видеоинструкции. Укажите последовательность действий и время каждого фрагмента; получите короткие реплики, которые удобнее читать в заданном темпе и затем согласовывать с изображением при монтаже.

  1. Перечислите действия и интервалы
  2. Прочитайте реплики по времени исходных кадров
Пример запроса

Перепиши озвучку инструкции по сборке полки: распаковка, крепление стоек, установка полок. Для каждого этапа дай короткую реплику, отметь паузу перед действием и не добавляй отсутствующих шагов.
