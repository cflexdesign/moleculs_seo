Для каких задач

Write.Homes относится к инструментам, которые помогают готовить текст по теме и требованиям к содержанию. Ещё одно направление работы: работать с информацией о недвижимости.

Проверка на своей задаче

Для первого задания в инструменте «Write.Homes» используйте короткий бриф с адресатом, назначением текста и обязательными фактами.

Оценивая результат инструмента «Write.Homes», уберите из результата обещания и сведения, которых не было в задании.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Write.Homes» «недвижимость» подготовьте объект с известными характеристиками и несколькими вариантами описания. Затем сверьте адрес, площадь и условия; сгенерированный текст не подтверждает состояние объекта.

Для сопоставления задач откройте раздел Email-маркетинг.

Практика в Молекуле

Цепочка писем для нового подписчика

Соберите содержание рассылки до настройки отправки в email-сервисе. Для каждого письма задайте полезный материал и повод написать; частоту и согласие получателя учитывайте отдельно.

  1. Укажите источник подписки и темы писем
  2. Проверьте полезность каждого сообщения
Пример запроса

Подготовь три письма подписчику курса фотографии: знакомство с программой, упражнение со светом, ответы на вопросы. Оставь место для подтверждённых дат и ссылки отписки.
