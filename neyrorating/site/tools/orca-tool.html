Перед первым заданием

Сценарий для знакомства с инструментом «Orca-Tool»: собирать слайды из материала по теме. Используйте краткое содержание выступления с одним главным тезисом на раздел с понятным критерием готовности; если подходящего режима нет, выберите другой инструмент.

При оценке инструмента «Orca-Tool» откройте экспорт и проверьте читаемость, порядок аргументов и переносы строк.

Разделы для выбора

Сопоставить инструмент «Orca-Tool» с другими вариантами можно в разделах Презентации и отчёты, Создать графику для презентации.

Для «Orca-Tool» можно также сравнить отдельный сервис и доступ к нескольким моделям через Молекулу.

Отчёт с выводом на каждом слайде

Пример запроса

По таблице заказов предложи структуру отчёта руководителю: изменение объёма, различия каналов и открытые вопросы. Для каждого слайда укажи данные-основание. Причины без подтверждения не заявляй.
