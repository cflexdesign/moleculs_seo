Для каких задач

В инструменте «Kira» можно разбирать текст договора и связанные документы. Ещё одно направление работы: разбирать содержимое документов.

Проверка на своей задаче

Для первого задания в инструменте «Kira» используйте обезличенный договор с условием, значение которого вам известно.

После обработки материала инструментом «Kira» сверьте вывод с полным текстом и применимым правом вместе с юристом.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Kira» «анализ документов» подготовьте файл с таблицей, заголовками и несколькими связанными разделами. Затем сверьте найденные значения с таблицей, а выводы с соответствующим разделом.

Для сопоставления задач откройте раздел Корпоративные системы (ERP).
