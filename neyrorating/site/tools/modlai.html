Для каких задач

Modl.ai используют для задачи: исследовать тему и разбирать найденную информацию. Ещё одно направление работы: готовить трёхмерный объект для проекта.

Проверка на своей задаче

Чтобы познакомиться с инструментом «Modl.ai», подготовьте вопрос с ограниченным предметом и понятным периодом.

После пробной задачи в инструменте «Modl.ai» проверьте, относятся ли выводы к нужной теме и подтверждаются ли исходными материалами.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Modl.ai» «3d-модели и объекты» подготовьте референс объекта с понятной формой и масштабом. Затем осмотрите модель с разных сторон и проверьте файл в целевом редакторе.

Для сопоставления задач откройте раздел AI-игры.

Практика в Молекуле

Развилка для игровой сцены

Подготовьте короткий эпизод с двумя решениями игрока. В Молекуле можно разобрать последствия каждого выбора; правила движка и игровую механику затем проверяет разработчик.

  1. Опишите место и цель игрока
  2. Проверьте, отличаются ли последствия решений
Пример запроса

Придумай сцену в заброшенной обсерватории: игрок выбирает между ремонтом антенны и поиском дневника. Для каждого решения опиши последствия и следующую реплику проводника.
