Для каких задач

Gymscore относится к инструментам, которые помогают подготавливать план занятий под заданные условия. Ещё одно направление работы: извлекать признаки и сведения из визуального материала.

Проверка на своей задаче

Для первого задания в инструменте «Gymscore» используйте описание опыта, доступного оборудования и ограничений нагрузки.

После обработки материала инструментом «Gymscore» обсудите нагрузку со специалистом при травмах или заболеваниях.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Gymscore» «распознавание изображений» подготовьте несколько изображений с заранее известным содержанием. Затем сопоставьте ответ с объектами в кадре и отдельно посмотрите ошибочные срабатывания.

Для сопоставления задач откройте раздел Фитнес.
