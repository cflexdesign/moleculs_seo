Для каких задач

В инструменте «HyNote» можно разбирать содержимое документов. Ещё одно направление работы: сокращать материал до основных положений.

Проверка на своей задаче

Проверить инструмент «HyNote» удобно на небольшом примере. Возьмите файл с таблицей, заголовками и несколькими связанными разделами.

После пробной задачи в инструменте «HyNote» сверьте найденные значения с таблицей, а выводы с соответствующим разделом.

Дополнительный сценарий

Для дополнительной задачи в инструменте «HyNote» «суммаризация» подготовьте небольшой документ с выводом, аргументом и существенной оговоркой. Затем проверьте, сохранена ли оговорка: без неё краткая версия может исказить вывод.

Работа с файлами

Если в вашем проекте нужны файлы PDF, перед длительной работой с «HyNote» проверьте пробный файл в целевом редакторе. Так можно заранее увидеть, сохраняются ли структура и нужное оформление.

Для сопоставления задач откройте раздел PDF и документы.

Практика в Молекуле

Ответ по PDF с местом в исходнике

Возьмите обезличенный документ или небольшой отрывок. Попросите ответ с цитатой и названием раздела, затем найдите это место самостоятельно. Так легче заметить пропущенное условие.

  1. Удалите ненужные персональные сведения
  2. Сверьте цитату с исходным документом
Пример запроса

По приложенному положению объясни, когда заявка считается принятой. Приведи цитату и название раздела. Если правило отсутствует или файл не прочитан, прямо укажи пробел.
