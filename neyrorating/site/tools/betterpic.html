Для каких задач

BetterPic предназначен для создания портретного материала по фотографиям. При отборе важны естественные черты лица и соответствие снимка тому месту, где он будет опубликован.

Проверка на своей задаче

Для первого задания в инструменте «BetterPic» используйте фотографию с разрешением на использование образа.

После обработки материала инструментом «BetterPic» сверьте черты лица с исходником и уберите варианты, меняющие личность человека.

Дополнительный сценарий

Для дополнительной задачи в инструменте «BetterPic» «обработка фото» подготовьте снимок, где хорошо различимы лицо, фон и мелкие детали. Затем сопоставьте изменённые участки с оригиналом, особенно края и мелкий текст.

Для сопоставления задач откройте раздел Аватары и портреты.

Портрет для страницы специалиста

Подготовьте деловой портрет для личного сайта на основе собственной фотографии. Задайте нейтральный фон, одежду и освещение; при просмотре сравните лицо с оригиналом и проверьте детали волос, очков и рук.

  1. Добавьте собственный снимок и пожелания
  2. Сравните лицо и аксессуары с оригиналом
Пример запроса

Создай деловой портрет по моему фото: нейтральная серая стена, мягкий боковой свет, тёмный жакет. Сохрани узнаваемые черты, форму очков и естественную текстуру кожи.
