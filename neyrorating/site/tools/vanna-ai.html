Vanna AI

Для каких задач

Vanna AI помогает создавать SQL-запросы средствами ИИ на основе Python. Продукт распространяется с открытым исходным кодом и поддерживает работу с разными базами. Доступные модели и способы интеграции дополняют подготовку запросов для выбранной пользователем среды обработки данных.

Проверка на своей задаче

Для первого задания в инструменте «Vanna AI» используйте схему таблиц и вопрос, для которого известен правильный ответ.

После обработки материала инструментом «Vanna AI» прочитайте SQL перед выполнением и проверьте соединения таблиц.

Дополнительный сценарий

Для дополнительной задачи в инструменте «Vanna AI» «генерация кода» подготовьте небольшую задачу в проекте, где уже есть проверка ожидаемого поведения. Затем просмотрите изменения до запуска и проверьте граничный случай.

Рабочее окружение

Для рабочего окружения с PostgreSQL, MySQL заранее определите, как вы будете передавать материалы в «Vanna AI» и возвращать результат в проект. Наличие подходящего способа подключения нужно проверить для вашего варианта доступа.

Для сопоставления задач откройте раздел SQL и запросы к БД.

Подготовить SQL-запрос по схеме таблиц

Покажите структуру таблиц и объясните, какой отчёт нужен по заказам. В Молекуле можно подготовить SQL-пример в текстовом диалоге; подключение к базе, проверку синтаксиса и выполнение запроса организуйте в собственной тестовой среде.

  1. Опишите таблицы, связи и используемый SQL-диалект.
  2. Приведите обезличенный пример ожидаемых строк отчёта.
  3. Проверьте соединения и фильтры до работы с реальной базой.
