Проверка на своём материале

Для оценки инструмента «All Things AI» в этом направлении возьмите один запрос и одинаковые исходные материалы для сравнения ответов. Сначала уточните доступность нужной операции, затем сравните результат с ожидаемым.

Проверяя результат инструмента «All Things AI», учтите режим модели и расход доступного лимита на каждый запрос.

Сравнение по задаче

Сопоставить инструмент «All Things AI» с другими вариантами можно в разделах Агрегаторы нейросетей, Ресурсы.

Для «All Things AI» можно также сравнить отдельный сервис и доступ к нескольким моделям через Молекулу.

Практика в Молекуле

Сравнить модели на своём задании

Молекула собирает разные модели в одном рабочем интерфейсе. Начните с небольшого задания и заранее определите критерии ответа, чтобы выбирать по полезности результата для вашей задачи.

  1. Зафиксируйте одинаковый исходный текст
  2. Сравните точность условий в полученных ответах
Пример запроса
