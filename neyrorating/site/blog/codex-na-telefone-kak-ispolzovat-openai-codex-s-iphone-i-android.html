Codex с телефона: как организовать работу с кодом

Как подготовить задачу для Codex, проверить изменения и защитить доступ к проекту при работе с телефона.

N
Редакция НейроРейтингаМатериал редакции · Правила рейтинга

Подготовьте доступ к проекту

Сначала проверьте в официальной документации OpenAI, какие интерфейсы Codex доступны вашему аккаунту. Возможности веб-интерфейса и локального клиента различаются; обычный чат с моделью не даёт ей доступ к репозиторию автоматически.

Опишите конкретное изменение

Укажите репозиторий, нужное поведение и способ проверки. Например: «В форме заказа покажи ошибку рядом с обязательным полем. Проверь отправку пустой формы и успешный заказ». Разбейте крупную задачу на изменения, которые удобно просмотреть на небольшом экране.

Проверьте результат перед публикацией

Читайте diff, результаты проверок и сообщение об ограничениях. Для изменения интерфейса откройте предпросмотр на телефоне. Не размещайте ключи доступа в тексте задачи; используйте предусмотренное проектом хранение секретов.

Инструменты для этой задачи

ChatGPTКлиентская поддержка

ChatGPT удобен для работы, которая начинается с вопроса или черновика. Пользователь передаёт задачу в чат, добавляет материалы и уточняет ответ по ходу разговора.

Сформулируйте изменение для работы с телефона

В текстовом чате Молекулы можно подготовить небольшое техническое задание и критерии проверки. Доступ к репозиторию, изменения кода и запуск тестов выполняйте в выбранной среде разработки.

Этапы выполнения
  1. Опишите одно наблюдаемое изменение
  2. Передайте задачу и проверки в среду разработки
Пример запроса

Помоги описать задачу разработчику: ошибка обязательного поля должна появляться рядом с полем формы. Укажи ожидаемое поведение и проверки пустой и успешной отправки. Репозиторий здесь не подключён.
