# SEO reports repository

The user requested that the results of «Сравнить SEO и модели конкурентов» be published on GitHub Pages, with completed updates sent to GitHub as in the course project.

## Scope and destination

- Repository: `https://github.com/cflexdesign/moleculs_seo.git`; remote `origin`, branch `main`.
- Website: `https://cflexdesign.github.io/moleculs_seo/`; Pages publishes the root of `main`.
- Publish finished artifacts from `outputs/` and the root site/documentation files allowed by `.gitignore`. Keep `work/`, raw captures, credentials and temporary files outside version control.
- Preserve the root `index.html` and `.nojekyll`. Keep both HTML reports in the same directory and update the index/download links when deliverable filenames change.
- This authorization covers this public repository and Pages site. Do not deploy elsewhere or publish raw chat/session data.

## Completed updates

- After a coherent batch of requested edits and relevant checks, inspect the diff and commit only this task's completed changes.
- Push to `origin/main` and verify the remote commit. Wait for the GitHub Pages deployment to succeed before claiming the live site has updated.
- Do not publish files while another process is writing them, stage unrelated changes, force-push, reset or discard others' work.
- If authentication, push or Pages deployment fails, preserve local work and report the actual state. Do not claim an upload succeeded merely because a local commit exists.
- During the initial setup, wait for the publishing task to finish before making concurrent Git commits or pushes.

This is an instruction for Codex after completed work, not a background filesystem watcher.
