Из новых целей 2 705 отсутствовали и в прежнем плане. MP-ID объединяет источники, дополняющие одну цель. Новая цель — кандидат страницы или технической реализации, а не уже опубликованный URL.

В каждой строке: источник и дата проверки, целевой адрес, описание задачи, наблюдаемая функция конкурента, поля формы или CMS, оригинальный промпт, модели и обработчики, результат, приёмка, метаданные SEO, содержание и перелинковка. Именованные API-модели являются кандидатами для проверки интеграции. Редакционные промпты обзоров не запускают описываемые сервисы.

Изучены извлечённые основные тексты, разделы, формы, CTA и ссылки доступных HTML-страниц. Применены предметные правила и индивидуальные описания; все 27 действующих инструментов Stiva и короткие динамические страницы дополнительно проверены по DOM. Ручной фактчекинг каждого предложения, закрытые кабинеты и платная генерация не заявляются. У LeanTech вне HTML-реестра остаются три PDF-приложения к документации программного продукта. Новостные утверждения конкурентов требуют первичной проверки при подготовке собственного материала.

Молекула повторно проверена по 502 известным адресам: 501 HTTP 200 и `/pricing` HTTP 404. SEO-счётчики относятся к извлечённому HTML, не измеряют позиции, трафик или фактическую индексацию. В HTML и Markdown перечислены адреса Молекулы для технической проверки.

Excel сохраняет исходные листы **«Страницы и правки»** и **«Промпты»** как срез 30 сентября; обновления находятся в **«Новые страницы»**. Полный повторный обход этой партии касается LeanTech и Stiva. **ruGPT остаётся в предыдущем срезе**, доступном ниже.
