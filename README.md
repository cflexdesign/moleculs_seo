Таблица содержит 597 строк: 493 обследованных публичных URL Молекулы, 100 кандидатов новых страниц и 4 инфраструктурных адреса. Для рабочих сценариев приложены 93 профиля с полями, маршрутами моделей, промптами и приёмкой. Данные зафиксированы 30 сентября 2026 года; новая таблица составлена по завершённому аудиту без повторного обхода сайтов.

Новые страницы и интеграции являются кандидатами после проверки спроса и backend. Обычная проверка шаблона не означает найденную ошибку каждого URL. Платные генерации не тестировались. Полнота sitemap ruGPT не подтверждена из-за блокировки: использован реестр найденных публичных страниц.

Три HTML-отчёта автономны и содержат встроенные данные, стили и скрипты. Сохраняйте их в одной папке: они ссылаются друг на друга.

GitHub Pages публикует корень ветки `main`. После отправки завершённых правок сайт обновляется автоматически. При смене имён файлов обновляйте ссылки в `index.html` и между отчётами. Рабочие материалы `work/` не публикуются.
